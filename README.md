# YK AI iPhone — ゆきAI 0.1.16 試作

iPhoneで使う会話・音声・おでかけアシスタントの開発用ソースです。
Apple Intelligenceが利用可能なiPhoneとiOS 26以降を想定しています。

## 機能

- 端末内AIによる日本語会話、性格・話し方の設定、短い返答、ストリーミング表示
- チャット一覧、新しいチャット、チャットごとの履歴、送信済み文章の編集
- iPhone標準音声とVOICEVOX（7キャラクター・25スタイル）、音声入力、背景音声再生
- 選択した写真の添付とOCR。任意ダウンロードの写真AIで端末内の見た目解析
- 「秋葉原に行きたい」などに短く反応し、会話内で徒歩・乗換案内を提案
- 現在地からの場所検索、ユーザーが開始するGPS徒歩ナビと音声案内
- Yahoo!乗換案内／Googleマップへの検索引き継ぎ、確認済み経路の貼り付け・発車前通知

電車の時刻・番線をAIの推測で確定しません。Yahoo!乗換案内のアプリ内部データを
自動取得する仕組みではありません。最新の時刻・運行状況は検索先で確認してください。
AIの自然さ・画像認識の正確さ・実際の徒歩ナビは実機での確認が必要です。

## データと通信

この公開パッケージはアプリのソース、テスト、ビルド設定だけです。
実際の会話、写真、位置情報、移動履歴、アカウント情報、署名鍵は含みません。
別の人がこのソースからアプリを作っても、他の端末のデータには接続しません。

- 会話・設定・記憶メモ・選択した画像は各iPhoneのアプリ内に保存します。
- アプリ独自のクラウド同期・広告・解析SDK・共有アカウントはありません。
- 会話はAppleの端末内モデルを使い、外部AIサービスへの自動切り替えはありません。
- 写真AIの任意ダウンロードはHugging Faceから行い、写真の解析は端末内で行います。
- 位置情報は周辺検索やユーザーが開始した徒歩ナビで使います。ナビ停止で追跡も停止します。
- 場所・経路検索には通信が必要です。検索語や検索に必要な座標を地図サービスへ送ります。
- GPS座標・移動軌跡は会話の保存データに記録しません。自分で入力した住所や目的地は
  会話・案内提案の一部として保存されます。
- アプリを削除すると保存した会話・画像も失われます。バックアップ対象外の保存領域を使います。

## ビルド

GitHubのリポジトリ直下に YK-AI-iPhone-v0.1-source.zip を置き、
同梱の .github/workflows/build-ios.yml をリポジトリ直下の同じパスに置きます。
Actions → Build iPhone IPA → Run workflow で手動実行します。
標準 macos-26 ランナーを使い、1件ずつ・最大45分で実行します。
ビルドには基本ロジック、シミュレーター、音声、UIの検証を含みます。
成功時の未署名IPAと検証結果はArtifactsに1日間保存されます。

Macではアーカイブを展開し、bash scripts/build-unsigned-ipa.sh で同じ検証を実行できます。
VOICEVOXの必要ファイルは公式配布元から取得し、固定したSHA256で確認します。
各ライブラリ・音声・モデルのライセンスと利用規約は別途適用されます。
音声の参照先は VoiceCatalog.json、写真モデルは VisualModel-LICENSES.txt にあります。

IPAは未署名です。自分のAppleアカウント用に署名してiPhoneへ導入する必要があります。
App Store配布や署名済みアプリの提供ではありません。
アカウントのパスワード・秘密鍵をリポジトリに登録しないでください。
